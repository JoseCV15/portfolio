# José Veiga - Personal Portfolio

A personal portfolio website showcasing my background, technical skills, and projects as an **Embedded Software Engineer | Customer Success/Support**.

The website highlights my experience in firmware developement, embedded systems, debugging, and technical support.

## 🌐 Overview
This portfolio was created to present my engineering background, showcase embedded systems projects, and make it easy to access my CV and contact informartion.

## 🛠️ Built With
. HTML5
. CSS3
. Javascript


## 📂 Project Structure
```text
portfolio/
├── index.html
├── css/style.css
├── js/script.js
├── assets/
└── README.md
```

## Run Locally
1. Clone the repository
```bash
git clone https://github.com/JoseCV15/portfolio.git
```
2. Navigate to the project directory and open index.htmlin your browser. Alternatively, use the Live Server extension
in VS code for local development

## 📦 Deployment

This website is deployed using **GitHub Pages**, configured in `.github/workflows/deploy.yml`.
On every push to the `main` branch, the workflow automatically.

For more information, consult the [GitHub Pages documentation](https://docs.github.com/en/pages).
